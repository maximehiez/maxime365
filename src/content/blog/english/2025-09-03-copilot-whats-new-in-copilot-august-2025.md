##### Introduction
Microsoft releases a monthly update to *Microsoft 365 Copilot* to keep admins and users up-to-date on productivity-enhancing features in Microsoft 365. The August 2025 release focuses on agent governance, usage measurement, security and risk management, and several conversational, visual, and creative capabilities for end users.

---

##### For administrators : Copilot Control System
**<u>Inventory of agents in the administration center</u>**

- *SharePoint agents* are joining the Microsoft 365 admin center's agent inventory, alongside agents developed internally and deployed across Microsoft 365 interfaces, agents created by users with *Microsoft Copilot Studio* in *Copilot Chat*, and third-party agents with governance actions (blocking, unblocking).
- Rollout : September

![image](/images/blog/copilot/copilot_whats_new_in_copilot_august_2025_001.png)
<br/>

**<u>Copilot Search</u>**

- Usage reports now track adoption of *Microsoft 365 Copilot Search* to guide your support plans.
- Rollout : August

![image](/images/blog/copilot/copilot_whats_new_in_copilot_august_2025_002.png)
<br/>

**<u>Approval workflow (Frontier & agents)</u>**

- A centralized request / approval flow arrives in the admin center (*<u>Copilot</u>*, then *<u>Agents</u>*, and *<u>Requested agents</u>*) for Frontier and Microsoft agents, reconciling experimentation and security requirements.
- Rollout : August

<br/><br/>

**<u>Billing : Message pack integration</u>**

- Ability to apply pre-paid credits (*Pay-As-You-Go*) for *Copilot Chat* with visibility and cost control (*<u>Copilot</u>*, then *<u>Billing & usage</u>*, and *<u>Pay-as-you-go services</u>*).
- Rollout : August

![image](/images/blog/copilot/copilot_whats_new_in_copilot_august_2025_003.png)
<br/>

**<u>Health of the agent park</u>**

- New controls to block, reassign or remove unowned agents and reduce operational risks.
- Rollout : August

![image](/images/blog/copilot/copilot_whats_new_in_copilot_august_2025_004.png)
<br/>

**<u>Purview Insider Risk Management for AI risks</u>**

- *Purview Insider Risk Management* (*IRM*) now detects sensitive prompts and responses in Copilot and Copilot Studio, calculates a risk level, and triggers appropriate policies (DLP, lifecycle governance, Entra conditional access).
- Rollout : August

![image](/images/blog/copilot/copilot_whats_new_in_copilot_august_2025_005.png)

---

##### For users : An enhanced Copilot experience
**<u>SharePoint agents : Access and reach</u>**

- Direct access to SharePoint agents from the Microsoft 365 Copilot app (display in the recently used agents bar).
- Open by default in Copilot rather than SharePoint.
- Discoverable in the Teams store with direct addition to a chat/channel (customized list per user).
- Rollout : September
<br/><br/>

**<u>Copilot Chat : New model & tools</u>**

- *Try GPT-5* button : Copilot uses GPT-5's real-time router to switch between a high-throughput model (simple tasks) and a deep reasoning model (complex tasks).
- Tools menu in the input area (Designer, Pages, pinned agents, Researcher, Analyst) to reduce back-and-forth.
- Email references with attachments (Word, Excel, PowerPoint, PDF, JSON, XML) directly included in the response, in Outlook and the Microsoft 365 Copilot app (with a Copilot license).
- PowerPoint presentation : Generation of a ready-to-use deck (structure, visuals, formatting) from the Copilot app ; with a license, taking into account the work context.
- Rollout : August

![image](/images/blog/copilot/copilot_whats_new_in_copilot_august_2025_006.png)
<br/>

**<u>Visual reasoning & image editing in Copilot Chat</u>**

- Upload PDF / Word / PowerPoint and ask the question *What’s shown in the image on page 4* to get visually anchored answers.
- Generate / edit images in natural language, visually track added elements (snippets).
- Side-by-side editor : Canvas + natural language guidance, upscale and auto-enhance without losing context.
- Rollout : September

![image](/images/blog/copilot/copilot_whats_new_in_copilot_august_2025_007.png)
<br/>

**<u>Create visuals in the Microsoft 365 Copilot app (without a Copilot license)</u>**

- Create features (posters, banners, infographics, images) are now available to users without a Copilot license.
- Rollout : Web / Windows / macOS in August, mobile in October.

![image](/images/blog/copilot/copilot_whats_new_in_copilot_august_2025_008.png)
<br/>

**<u>Summary in Edge for Business</u>**

- Right-click on the webpage and then *<u>Summarize with Microsoft 365 Copilot</u>* to condense a dense webpage without leaving the tab.
- Rollout : August
<br/><br/>

**<u>Custom dictionaries for Copilot in Teams</u>**

- Upload industry-specific dictionaries (English, Spanish, Japanese, French, German, Portuguese, Italian, and simplified Chinese) from the Copilot settings in the admin center ; benefits Copilot and Teams meeting recap.
- Déploiement : Juillet

---

##### Recommended action plan for administrators
1. Verify the presence of reports and controls (Search usage, unowned agents, Pay-As-You-Go / credits)
2. Enable the Frontier / agent approval workflow before broadly expanding usage
3. Prepare for the arrival of SharePoint agents (inventory, governance, publishing in Teams)
4. Update your Purview IRM / Adaptive Protection policies to cover sensitive prompt scenarios
5. Inform your users of new gestures (Try GPT-5, Tools menu, email references, Edge summary, image creation/editing)

---

##### Conclusion
This August 2025 wave strengthens agent governance, brings AI risk detection to Purview, and streamlines daily usage (on-demand GPT-5, centralized tools, image understanding, presentation generation, page summaries). Administrators gain control, users gain speed and context—enough to accelerate adoption while maintaining control.
