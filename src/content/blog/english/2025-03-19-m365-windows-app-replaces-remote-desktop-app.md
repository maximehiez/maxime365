##### Introduction
Microsoft has announced that the *Remote Desktop* app for Windows, available on the *Microsoft Store*, will no longer be supported or available for download starting May 27, 2025. Users will need to switch to the new *Windows App* to continue accessing *Windows 365*, *Azure Virtual Desktop*, and *Microsoft Dev Box*.

---

##### Why this change ?
Microsoft claims that the new Windows App offers improved features compared to the Remote Desktop app. Here are some of the improvements:
- Unified access : Manage cloud PCs and virtual desktops from a single, simplified interface.
- Improved usability : Customizable home screens, support for multiple monitors, and dynamic screen resolutions.
- Improved performance : Device redirection, smoother integration with Microsoft Teams, and easier account switching.<br/><br/>

![image](/images/blog/m365/m365_windows_app_replaces_remote_desktop_app_001.png)

---

##### User Impact
**<u>Windows 365, Azure Virtual Desktop, and Microsoft Dev Box users</u>**

Users of these services will need to switch to the new Windows App to continue accessing them. Connections via the Remote Desktop app will be blocked after May 27, 2025.
<br/><br/>

**<u>Remote Desktop Services users</u>**

For those connecting to *Remote Desktop Services*, Microsoft recommends using *RemoteApp* and *Desktop Connection* until the new Windows App is fully compatible.
<br/><br/>

**<u>Remote Desktop users</u>**

For those connecting to remote desktops via the Remote Desktop app, they will need to use the native app built into Windows until support for this connection type is added to the new Windows App.

![image](/images/blog/m365/m365_windows_app_replaces_remote_desktop_app_002.png)

---

##### Transition preparation
Microsoft encourages administrators to prepare their organizations by encouraging Remote Desktop users to begin their transition to the new Windows App. Here are some steps to facilitate this transition:
- Download the Windows App : Available from the Microsoft Store or directly from the Microsoft website.
- Test compatibility : Check compatibility with your current setup to avoid surprises.
- Update internal resources : Update user guides, support documentation, and administrative materials.

---

##### Known issues and limitations
It's important to note that the new Windows App may have functional gaps compared to the Remote Desktop app. Microsoft recommends regularly reviewing the list of known issues and limitations to stay informed of updates and resolutions.

---

##### Conclusion
The transition to the new Windows App represents a significant milestone for Windows 365, Azure Virtual Desktop, and Microsoft Dev Box users. By offering enhanced features and improved performance, this new app aims to improve the user experience while addressing the growing needs of virtual desktop management.
