##### Introduction
Microsoft a annoncé que l'application *Remote Desktop* pour Windows, disponible sur le *Microsoft Store*, ne sera plus prise en charge ni disponible au téléchargement à partir du 27 Mai 2025. Les utilisateurs devront passer à la nouvelle *Windows App* pour continuer à accéder à *Windows 365*, *Azure Virtual Desktop* et *Microsoft Dev Box*.

---

##### Pourquoi ce changement ?
Microsoft affirme que la nouvelle Windows App offre de meilleures fonctionnalités par rapport à l'application Remote Desktop. Voici quelques-unes des améliorations :
- Accès unifié : Gestion des PC cloud et des bureaux virtuels à partir d'une interface unique et simplifiée.
- Utilisabilité améliorée : Écrans d'accueil personnalisables, prise en charge de plusieurs moniteurs et résolutions d'écran dynamiques.
- Performance améliorée : Redirection des périphériques, intégration plus fluide avec Microsoft Teams et changement de compte simplifié.<br/><br/>

![image](/images/blog/m365/m365_windows_app_replaces_remote_desktop_app_001.png)

---

##### Impact sur les utilisateurs
**<u>Utilisateurs de Windows 365, Azure Virtual Desktop et Microsoft Dev Box</u>**

Les utilisateurs de ces services devront passer à la nouvelle Windows App pour continuer à y accéder. Les connexions via l'application Remote Desktop seront bloquées après le 27 Mai 2025.
<br/><br/>

**<u>Utilisateurs de Remote Desktop Services</u>**

Pour ceux qui se connectent aux *Remote Desktop Services*, Microsoft recommande d'utiliser *RemoteApp* et *Desktop Connection* jusqu'à ce que la nouvelle Windows App soit entièrement compatible.
<br/><br/>

**<u>Utilisateurs de Remote Desktop</u>**

Pour ceux qui se connectent à des bureaux distants via l'application Remote Desktop, ils devront utiliser l'application native intégrée dans Windows jusqu'à ce que la prise en charge de ce type de connexion soit ajoutée à la nouvelle Windows App.

![image](/images/blog/m365/m365_windows_app_replaces_remote_desktop_app_002.png)

---

##### Préparation à la transition
Microsoft encourage les administrateurs à préparer leurs organisations en incitant les utilisateurs de l'application Remote Desktop à commencer leur transition vers la nouvelle Windows App. Voici quelques étapes pour faciliter cette transition :
- Télécharger Windows App : Disponible sur le Microsoft Store ou directement depuis le site de Microsoft.
- Tester la compatibilité : Vérifiez la compatibilité avec votre configuration actuelle pour éviter les surprises.
- Mettre à jour les ressources internes : Mettez à jour les guides utilisateurs, la documentation du support technique et les matériaux administratifs.

---

##### Problèmes connus et limitations
Il est important de noter que la nouvelle Windows App peut présenter des lacunes fonctionnelles par rapport à l'application Remote Desktop. Microsoft recommande de consulter régulièrement la liste des problèmes connus et des limitations pour rester informé des mises à jour et des résolutions.

---

##### Conclusion
La transition vers la nouvelle Windows App représente une étape importante pour les utilisateurs de Windows 365, Azure Virtual Desktop et Microsoft Dev Box. En offrant des fonctionnalités améliorées et une meilleure performance, cette nouvelle application vise à améliorer l'expérience utilisateur tout en répondant aux besoins croissants de la gestion des bureaux virtuels.
