##### Introduction
Alors que Microsoft pousse fortement vers le cloud avec *Microsoft Teams*, l’éditeur n’abandonne pas pour autant les organisations ayant des besoins critiques en communications unifiées sur site. Avec la sortie de *Skype for Business Server Subscription Edition (SE)*, Microsoft propose une version modernisée, durable et plus facile à maintenir de sa plateforme historique.

---

##### Qu’est-ce que Skype for Business Server SE ?
Skype for Business Server SE est une édition à abonnement de Skype for Business Server, conçue pour remplacer les versions traditionnelles à cycle de vie fixe. Elle repose sur le code de la version *2019 CU8HF1*, mais adopte un modèle de mise à jour continue (*Modern Lifecycle Policy*), sans version majeure future.

Ce qui change :
- Plus de versions *année* (ex. 2015, 2019), SE est une plateforme évolutive
- Les mises à jour sont cumulatives et régulières, sans migration complète nécessaire
- Le support est continu, tant que l’environnement reste à jour

---

##### Pourquoi une mise à niveau *in-place* est recommandée ?
Pour les clients déjà sur Skype for Business Server 2019, Microsoft recommande une mise à niveau sur place (*in-place upgrade*) vers SE. Contrairement aux migrations traditionnelles (*side-by-side*), cette méthode est :
- Plus rapide : Pas besoin de déployer une nouvelle topologie.
- Moins risquée : Aucun changement de prérequis, de fonctionnalités ou de configuration.
- Éprouvée : Le code SE est identique à celui de 2019 CU8HF1, à l’exception du nom, du contrat de licence et du numéro de build.

Ce qui ne change pas :
- Aucune fonctionnalité supprimée ou ajoutée
- Aucune modification des prérequis matériels ou logiciels
- Aucune interruption majeure pour les utilisateurs

---

##### Faible risque de mise à jour
Contrairement aux versions précédentes, où chaque nouvelle mouture impliquait des changements majeurs de code, de fonctionnalités et de prérequis, la Subscription Edition a été conçue comme une évolution incrémentale de la version 2019 :
- Le code de base est identique à celui de la version 2019
- Les fonctionnalités ont été stabilisées avant la sortie
- Les correctifs de sécurité et les mises à jour ont été portés depuis la version précédente
- Aucun changement majeur dans les prérequis matériels ou logiciels
- Le processus de mise à niveau est documenté, testé et validé par Microsoft

En résumé, il ne s’agit pas d’un *nouveau produit* mais d’une extension naturelle de l’existant.

---

##### Nouveautés techniques et roadmap
Bien que la version initiale de SE soit identique à 2019 CU8HF1, Microsoft prévoit d’introduire progressivement :
- Des améliorations de l’installateur
- Une compatibilité élargie avec d’autres composants Microsoft (ex. Exchange SE)
- De nouvelles fonctionnalités dans les futures mises à jour cumulatives

---

##### Pourquoi choisir SE en 2025 ?
Pour les organisations qui :
- Ont des besoins réglementaires ou de souveraineté empêchant une migration vers le cloud
- Souhaitent prolonger la durée de vie de leur infrastructure existante
- Veulent éviter les migrations coûteuses tous les 3 à 5 ans

SE offre une voie durable, moderne et alignée avec les pratiques de gestion actuelles.

---

##### Conclusion
Avec Skype for Business Server Subscription Edition, Microsoft propose une solution hybride entre stabilité sur site et agilité du cloud. Grâce à une mise à niveau sur place simple et sans risque, les organisations peuvent prolonger la valeur de leurs investissements tout en bénéficiant d’un modèle de support moderne. Une option stratégique pour celles qui ne sont pas encore prêtes à basculer entièrement vers Microsoft Teams.
