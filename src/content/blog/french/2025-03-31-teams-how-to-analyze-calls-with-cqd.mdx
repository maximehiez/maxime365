##### Introduction
Le *Teams Call Quality Dashboard* (*CQD)* de Microsoft est un outil puissant conçu pour aider les administrateurs à surveiller et à améliorer la qualité des appels téléphoniques au sein de leur organisation. Le modèle Power BI permet de générer des rapports d’historique sur le nombre d’appels traités par les standards automatiques, les files d’attente et la performance des agents.

---

##### Prérequis
**<u>Power BI Desktop</u>**
- Power BI Desktop doit être installé.

**<u>Rôle d’administrateur</u>**
- Un compte avec le rôle *Administrateur Global*, *Administrateur Teams* ou *Teams Communications Administrator* pour charger les données.

---

##### Étape 1 : Télécharger les modèles CQD pour Power BI
Téléchargez les modèles CQD via https://www.microsoft.com/download/details.aspx?id=104623.

---

##### Étape 2 : Charger les données
Ouvrez le fichier *.pbit* téléchargé en double cliquant dessus. Power BI devrait démarrer.

Cliquez sur *<u>Compte professionnel</u>*.

![image](/images/blog/teams/tuto/teams_how_to_analyze_calls_with_cqd_001.png)

Entrez votre compte administrateur Microsoft 365, puis cliquez sur *<u>Se connecter</u>*.

![image](/images/blog/teams/tuto/teams_how_to_analyze_calls_with_cqd_002.png)

---

##### Étape 3 : Accéder aux données
**<u>Auto Attendant</u>**

Le rapport présente l'analyse des appels entrants dans les standards automatiques. Il est possible de filtrer sur quel compte de ressource de standard automatique vous souhaitez obtenir les données.

![image](/images/blog/teams/tuto/teams_how_to_analyze_calls_with_cqd_003.png)
<br/>

**<u>Call Queue</u>**

Le rapport présente l'analyse des appels entrants dans les files d'attente. Il est possible de filtrer sur quel compte de ressource de file d'attente vous souhaitez obtenir les données.

![image](/images/blog/teams/tuto/teams_how_to_analyze_calls_with_cqd_004.png)
<br/>

**<u>Agent Timeline</u>**

Le rapport présente l'analyse chronologique de la prise des appels par les agents dans les files d'attente. Il est possible de filtrer sur quel agent et sur quel compte de ressource de file d'attente vous souhaitez obtenir les données.

![image](/images/blog/teams/tuto/teams_how_to_analyze_calls_with_cqd_005.png)

<Notice type="note">Les données seront disponibles pour tous les appels de 28 jours et moins, avec un délai de 30 minutes avant d’avoir la possibilité de les analyser.</Notice>

---

##### Conclusion
Vous savez maintenant comment récupérer et analyser les appels entrants dans Teams via les modèles CQD pour Power BI.
