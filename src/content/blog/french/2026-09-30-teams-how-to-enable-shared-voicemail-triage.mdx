##### Introduction
La messagerie vocale partagée d'une file d'attente *Microsoft Teams* pose toujours le même problème ; les messages arrivent dans une boîte commune, sans hiérarchie ni contexte, et quelqu'un doit tous les écouter pour savoir lesquels sont urgents. Sur une file d'attente qui reçoit plusieurs dizaines de messages par jour, le tri consomme plus de temps que le traitement.

Teams propose désormais un tri automatique des messages vocaux partagés, réalisé par le modèle de langage du *Substrate* (*LLM*). Le modèle génère un résumé, marque les messages urgents, identifie les actions à mener et attribue une catégorie, directement dans le message livré.

---

##### Prérequis
**<u>Téléphonie Microsoft Teams activée</u>**
- Une file d'attente configurée avec une messagerie vocale partagée.
- Teams Queues App déployée.

**<u>Rôle d'administrateur</u>**
- Un compte avec le rôle *Administrateur Global* ou *Administrateur Teams* pour accéder au Microsoft Teams Admin Center.

---

##### Étape 1 : Se connecter à Microsoft Teams en PowerShell
Connectez-vous à Microsoft Teams via la commande PowerShell suivante :
```powershell
Connect-MicrosoftTeams
```

---

##### Étape 2 : Créer le modèle de tri
Créez le modèle de tri des messages vocaux partagés via la commande PowerShell suivante :
```powershell
New-CsSharedVoicemailTriageSettingsTemplate -Name "IT Support - Triage" -Description "Triage template for the IT Support shared voicemail" -EnableVoiceToTextSummary $true -EnableUrgencyDetection $true -EnableCallToActionDetection $true -EnableCategoryDetection $true
```

Chacun des quatre paramètres pilote un champ ajouté au message vocal :
- <u>EnableVoiceToTextSummary</u> : Génère un résumé d'un paragraphe, dont la première phrase reprend l'intention de l'appelant, suivie des dates, heures, actions attendues et coordonnées
- <u>EnableUrgencyDetection</u> : Identifie les messages sensibles au temps et les marque comme *Important*
- <u>EnableCallToActionDetection</u> : Repère les tâches à réaliser et leur attribue un type standard, rappel, réponse par courriel, prise de rendez-vous, report ou annulation
- <u>EnableCategoryDetection</u> : Attribue une catégorie sous forme de nom court reprenant l'intention principale, avec des catégories standards comme *Junk* ou *Harmful Content* lorsque c'est pertinent

Les quatre paramètres valent *true* par défaut, il suffit donc de préciser ceux que vous souhaitez désactiver.

---

##### Étape 3 : Assigner le modèle à la file d'attente
Assignez le modèle à la file d'attente via la commande PowerShell suivante :
```powershell
Set-CsCallQueue -Identity e988ce9d-b140-bfa9-44ef-e92959522bf9 -SharedVoicemailTriageSettingsTemplateId b0908cc3-8d87-49a1-a25b-c5a7d76c2689
```

<Notice type="tip">Remplacez les 2 ID par vos valeurs. Le modèle peut également être assigné à un standard automatique ou à un *Main Line Attendant* avec la même approche.</Notice>

---

##### Étape 4 : Ajuster ou retirer le modèle
Les réglages d'un modèle existant se modifient sans le recréer :
```powershell
Set-CsSharedVoicemailTriageSettingsTemplate -Identity b0908cc3-8d87-49a1-a25b-c5a7d76c2689 -EnableCallToActionDetection $false
```

Pour désactiver complètement le tri, retirer le paramètre du modèle ne suffit pas. Il faut détacher le modèle de la file d'attente, du standard automatique ou du Main Line Attendant concerné, ou supprimer le modèle lui-même :
```powershell
Remove-CsSharedVoicemailTriageSettingsTemplate -Identity b0908cc3-8d87-49a1-a25b-c5a7d76c2689
```

---

##### Valider le résultat
Le résultat est visible sur les messages vocaux reçus après l'assignation. Les champs générés par le modèle apparaissent dans le message livré et sont consultables depuis l'application *Queues App*.

![image](/images/blog/teams/tuto/teams_how_to_enable_shared_voicemail_triage_001.png)

<Notice type="note">Le traitement est réalisé en temps réel et les résultats sont stockés dans votre environnement Exchange, comme partie intégrante du message vocal livré. Le paramètre *SharedVoicemailTriageSettingsTemplateId* des files d'attente reste réservé aux clients inscrits à la préversion privée des applications vocales, la date de disponibilité générale n'étant pas annoncée.</Notice>

---

##### Conclusion
Le gain se mesure surtout sur les files à fort volume, où le résumé et le marqueur d'urgence évitent d'écouter chaque message pour décider de l'ordre de traitement. La catégorisation *Junk* rend en prime service sur les numéros exposés au démarchage.<br/><br/>
Vous savez maintenant comment activer le tri automatique des messages vocaux partagés dans vos files d'attente Teams.
